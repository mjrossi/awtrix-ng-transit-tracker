# v0.7.0 Library: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `pkg/` something a Go programmer outside this repository can use and understand.

**Architecture:** Configuration plumbing leaves the core for `pkg/transit/registry`. Examples are tests; one separate module, built in CI, proves nothing needed is internal.

**Tech Stack:** Go standard library, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-25-clock-cli-library-design.md`, "Release 3"

## Global Constraints

- One module; no stability promise before 1.0; no new modules.
- No behavior change in any command; existing golden files do not change.
- US spelling; doc comments at one or two sentences.
- Each task ends with `go test -race -count=1 ./...` and `golangci-lint run` passing. Do not run `mise` without asking.
- Branch `library`, after v0.6.0 is merged. Names below from v0.6.0 are as in its plan; check them against the code first.

## Review Focus

1. Importing only `pkg/transit` pulls in no third-party package. (Task 1)
2. `New(cfg, nil)` in every HTTP provider works with no client. (Task 3)
3. The example module builds from a clean checkout with the module's lowest Go version. (Tasks 2 and 4)

### Task 2: Lower the Go requirement

**Files:** Modify `go.mod`, `.golangci.yml` (`run.go`), `.github/workflows/ci.yml`, `CLAUDE.md`.

- [ ] **Step 1:** Set `go 1.26.0` and `toolchain go1.27.3`. Run `GOTOOLCHAIN=go1.26.0 go build ./... && GOTOOLCHAIN=go1.26.0 go test ./...`; this downloads Go 1.26.0 into the module cache. If a dependency or the code needs 1.27, use `go 1.27.0` and note why in the pull request.
- [ ] **Step 2:** Add a CI job `oldest-go`: `actions/setup-go` with the version in the `go` line, `GOTOOLCHAIN: local`, running `go build ./...` and `go test ./...`.
- [ ] **Step 3:** CLAUDE.md, "Tooling": the `go` line is the oldest supported version; mise pins the development one. Commit "Lower the Go version importers need".
