# v0.6.0 CLI: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `urbanist-timetable departures`, and make the clock a command group of a CLI that needs no clock.

**Architecture:** `gtfsrt` gains a disk cache for the schedule. Provider resolution moves from `internal/config` to `pkg/transit/catalog`, and `providers.Open` builds a provider from a name. A new `internal/termout` renders departures as text or JSON; commands stay thin.

**Tech Stack:** Go 1.27.3 standard library, urfave/cli v3, go-toml v2, go-cmp.

**Spec:** `docs/superpowers/specs/2026-11-25-clock-cli-library-design.md`, "Release 2"

## Global Constraints

- No new modules. US spelling. Table-driven tests, `go-cmp` diffs, no live calls in tests.
- Providers use `Query.Now` or the cache's `now`, never the wall clock.
- Secrets never reach output, errors, or files on disk. No URL in a cache file or its name.
- Nothing past a provider imports a provider package; `internal/config` imports `catalog`, not `providers`.
- Existing golden files do not change.
- Comments explain a non-obvious why only. Every user-visible change adds a line under `Unreleased` in `CHANGELOG.md` in the same commit.
- Each task ends with `go test -race -count=1 ./...` and `golangci-lint run` passing. Do not run `mise` without asking.
- Branch `cli`, after v0.5.0 is merged.

## Review Focus

1. A headsign or line name with escape sequences or newlines: printed without control characters, so a feed cannot drive the terminal. (Task 6)
2. One of several stops fails: the others are shown with a warning, exit 0; all failing exits 1. (Task 7)
3. The same stop given twice: departures are not doubled. (Task 7)
4. Accented names ("São Sebastião"): columns align by characters, not bytes. (Task 6)
5. Ctrl-C during a first schedule download: exits 0 and leaves no partial file in the cache. (Task 2)

		calls++
		return "old", &StaleError{Err: errors.New("down")}
	})
	now := time.Date(2026, 11, 25, 8, 0, 0, 0, time.UTC)

		if v != "old" || err == nil || err.Error() != "down" {
			t.Errorf("Get = %q, %v; want the stale value and its error", v, err)

}
